# Moved

This repository has been retired. The scroll-driven skill browser now lives in the
repository it indexes:

### → [github.com/bughunt8/skills](https://github.com/bughunt8/skills) — in [`site/`](https://github.com/bughunt8/skills/tree/main/site)

Keeping the page in the same repository as the skills means it is generated from
that repository's own `skills/` directory, so it cannot disagree with the commit it
ships from, and adding a skill updates the page in the same commit.

Nothing here is maintained. This repository is archived and its GitHub Pages site
has been taken down.
